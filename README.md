# Nephele SARS-CoV-2 pipeline

This pipeline assembles SARS-CoV-2 genome and calls mutations from Illumina sequence data generated using a tiled multiplexed primers strategy (ARTIC protocol). Users can select from primers such as ARTIC and NEB-Varskip. Alternatively, users can upload a custom primers design (in .bed format).

This pipeline is now retired from the Nephele platform.  We provide the code and resources used by the pipeline here as is.
